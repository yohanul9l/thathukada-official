# Thattukada (തട്ടുകട) • Ultra-Minimalist Malayalam Discord Website

A minimalist, modern, and visually stunning landing page for the **Thattukada** Discord community (`https://discord.gg/malayalam`).

---

## ✨ Design Philosophy & Architecture

1. **Ultra-Minimalist Aesthetic**:
   - Zero visual clutter, no distracting neon glows, no redundant cards, and no loud promotional banners.
   - Generous breathing room, precise alignment, and disciplined visual hierarchy.
   - Subdued, architectural border radius (`6px`–`16px`) instead of oversized bubble elements.

2. **Exclusive Green Color Scheme**:
   - **`#224A28`**: Deep primary dark green surface and container base.
   - **`#27542E`**: Medium dark green for elevated cards and hairline structure.
   - **`#2C5F34`**: Medium green for active component indicators and tab borders.
   - **`#449351`**: Vibrant emerald green for primary actions, active states, and focused interactions.
   - Clean high-contrast typography (`#f5f9f6` primary and `#c2dcd5` / `#88a992` secondary sage).

3. **Restrained, Subtle Liquid Glass**:
   - Light, translucent frosted glass (`rgba(34, 74, 40, 0.40)`) with hairline borders (`1px solid rgba(68, 147, 81, 0.16)`).
   - Natural, unobtrusive backdrop blur (`14px`) without heavy dropshadows or noisy reflections.

4. **Serene Rain Window Simulation**:
   - Gentle, low-noise raindrop physics on canvas.
   - Soft, slow ambient atmospheric pulses behind the glass pane.
   - Optional procedural rain audio toggle with built-in Web Audio synthesis (zero external files).

5. **Essential Interactive Features**:
   - **Interactive Kattan Chaya Vibe Generator**: One-click topic dispenser for server conversation starters with liquid tea animation.
   - **Curated Server Directory**: Categorized channels for Voice Lounges, Cinema & Music, Gaming, and Food.
   - **FAQ Accordion**: Hairline-divided, smooth accordion.
   - **Fast Copy Link & Join**: One-click clipboard copy with clean feedback and direct link to `https://discord.gg/malayalam`.

---

## 🚀 How to View
Open `index.html` in any web browser (Chrome, Edge, Safari, Firefox). 100% self-contained static site.
